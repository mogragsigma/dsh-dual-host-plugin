## 变更范围

本次是 alpha.69 基础上的未发布 UI 工作树，不是已部署的新插件版本。
本地、云端共用同一前端实现，不增加双端不同的业务分支。

| Before | After | Why |
| --- | --- | --- |
| 双端工作台 | 大肥鱼bot | 统一主入口、页面标题与导览返回文案；内部 ID 不变 |
| 大标题、宣传横幅、常驻介绍 | 紧凑标题和带圈问号 | 主要空间让给操作和真实状态，说明仍可按需查看 |
| 双端连接／操作边界独立面板 | 访问端按钮左侧“连接与边界” | 减少重复框体，不隐藏实时错误或权限确认 |
| 协作会话占独立长区域 | 执行区内切换普通批次／协作会话 | 保留两类账本含义，但不让空列表占据整屏 |
| 执行记录全部展开 | 时间线、每页 5 条、桌面按钮侧置 | 减少高度；前端分页不触发新读取或执行 |
| 导览页号、营销标题分行 | 页号、操作标题、说明合并 | 保留 1/6 和进度条；角色形象缩小并保留变化 |

主要源文件为 `ui-source/workbench-client.js`、`overrides.css`、
`onboarding/app.jsx`、`components.jsx`、`style.css`。
生成文件仍经原构建脚本产生，没有手改打包 JS。

## 回归证据

- 9 份定向测试文件，共 **66 项通过，0 失败、0 跳过**。
- 新增分页首末页、快照缩小、空数据、同快照保页、显示名／内部 ID、权限提示保留测试。
- 原 UI 契约、仓库／交付展示、凭据按钮布局、导览 RPC、原生 Web 入口状态回归通过。
- 浏览器使用编译后的真实组件和模拟数据，不连接 ECS、正式 DSH、模型、IM 或 Gitee。
- 导览六页在宽屏与 390px 容器下逐页检查，无按钮互相重叠、无横向溢出。
- 普通批次 12 条分 3 页、协作 7 条分 2 页；翻页请求计数保持不变。
- 手动刷新后 12 条变为 2 条／0 条，回到合法第一页；读取失败仍禁用会话导航。
- 问号与边界说明支持键盘打开、Escape 关闭、焦点返回；必填阻断与跳过保持。
- 本地／云端角色与右侧栏使用同一实现；角色不会由用户切换控件改变真实 Host 身份。

初次定向测试中，一条历史测试仍要求早于 alpha.69 的全局规则长句。
已核对冻结规则确为压缩表述，仅修正该测试断言；没有改动产品规则来迁就测试。
模拟预览第一次遍历模型页时，夹具缺少 `secret_status.slots`，修正模拟响应后重验通过。
这两项初始失败保留于阶段证据，不计作产品或真实凭据服务故障。

## 保持与待办

245 个打包文件中，只有生成的 `workbench-client.js` 改变，另外 **244 个逐文件 SHA-256 保持**。
其中包含后端、RPC、调度、审批、通知、写入门禁、全局规则、Skill、角色素材及版本清单。
没有修改正式安装、日常配置、DSH 或第三方源码；没有重启、commit、push 或发布。

本轮仅客户端分页：普通工作区已有接口最多读取最近 50 次，单任务详情最多最近 10 次。
更早记录的服务端翻页不在本轮授权范围；界面明确标注“已加载”，不假称覆盖全部历史。

默认通知策略、真实自动通知与其他剩余验收见 [待办记录](ui-compact-and-notification-backlog.md)。
此前正式切换和定时任务证据仍在第 63 阶段，不以本轮模拟数据冒充新的正式联调。
正式切换前另行确认候选版本、回滚基线和名称指引同步；不借改名改变规则／Skill 的执行边界。
