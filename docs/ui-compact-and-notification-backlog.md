## 本轮界面范围

- 显示名称改为“大肥鱼bot”；内部插件 ID、路由、工具、协议保持。
- 静态介绍改为带圈问号说明，保留可变大肥鱼形象、浅蓝白色和清楚的模块分界。
- “双端连接／操作边界”合并到顶端访问端按钮左侧的小入口，不再独占框体。
- 执行结果／会话使用紧凑时间线和前端分页，刷新仍为手动。
- 只分页已有快照，不新增查询：普通工作区最多加载最近 50 次，任务详情最多最近 10 次。
  页面明确显示“已加载”，不暗示全部历史都已可翻页；更早历史的服务端分页不在本轮范围内。
- 不折叠运行错误、失效状态、必填校验或授权确认；不改变任何执行动作。
- 当前为 alpha.69 基础上的 UI 工作树候选，不是新正式版本；打包版本与正式切换另行确认。

## 默认通知问题

最新需求撤回固定本地：在导览 3/6 选择本地或云端机器人作为默认交办与结果返回端。
原 S65 仅记录需求、不改通知代码；S66 的实现和部分回归见 [候选接线](notification-defaults-alpha32.md)。
真实新装双端与通知闭环尚未完成，不视为正式生效。

1. 发送机器人身份来自用户实际配置，不写死名称、App ID 或内部 bot ID。
2. 机器人账号不等于收件位置；需选择或核验私聊／群，用户无需输入内部 chat ID。
3. 一次明确授权形成可审计、可撤销的默认通知策略；新任务继承，任务可覆盖或关闭。
4. 默认发送完成／失败摘要和成果入口，不隐含上传全部文件；群发和文件权限分别核验。
5. 选本地时离线通知持久排队，云端继续执行；选云端时不依赖 Mac 在线，不静默切换机器人。
6. 不因后来配置默认策略而补发历史任务，不把通知同意当开发、commit 或 push 授权。
7. 逐任务来源证据和导览默认授权分开记录；候选已实现持久化与继承，真实联调仍待完成。
8. “发到这里”的原会话识别必须有可信来源，不根据昵称或第三方私有状态猜测。

## 剩余测试

### 已有真实证据

- 正式双端 alpha.69 切换、原生聊天／真实 IM、工作台／侧栏与历史账本保护已通过。
- 本地 IM 自然语言交办一次云端延迟任务已完成：约定延迟 120 秒，1 批，实际结果 22。
- 等待时入口不占用；按任务名称查询、成果介绍及原云端执行会话跳转通过。
- 以上主动查询不是自动通知。正式环境默认通知仍待，不能引用隔离群通知代替该项。

### 默认通知接线后必测

- 导览 3/6 动态账号／接收位置绑定：单账号、多账号、未配置、权限不足和目标失效。
- 新定时任务继承默认策略；覆盖／关闭、拒绝权限、撤销和策略修改不重放历史。
- 选择本地或云端分别验证：云端完成／失败 → 所选端 IM 发送 → 平台回执；接受不等于已读。
- Mac 离线排队、恢复发送、Host 重启去重；发送结果未知时查询原操作而非盲重发。
- 群／私聊不串发，成果链接／手机入口正确，摘要与文件权限分开。

### 本轮 UI 定向验收

- 双端角色、空数据、失败／过期快照、窄屏和右侧栏；问号支持键盘、触摸与关闭焦点恢复。
- 执行列表首末页、空页、刷新后页数缩小、批次／协作区分；翻页不新增 RPC。
- 原手动刷新、任务搜索、成果入口、导航门禁、导览必填校验与确认文案保持。
- 可变角色素材保持；减少动态效果设置生效；无按钮重叠或横向溢出。
- 后端及规则／Skill 字节基线保持；无需重跑真实开发、模型、审批、Git 写入链路。

### 后续非 UI 问题

- 模型自述请求次数与原生调用记录不一致时，以实际记录为准，补权威摘要回归。
- 自然语言查询不应把视图缺少时间字段说成账本未记录，补开始／完成时间事实准确性。
- Windows 真机全链路、市场发布元数据与素材许可复核仍为后续事项，不借本轮扩展。
