# 来源路由最小接线

本模块只扩展云端既有 Coordinator，不增加第四条人工交办入口、IM 消费者或个人凭证系统。
首个真实来源尚未接入；合成事件/确定性模型验收不能证明真实平台连通或语义正确率。

## 接缝

- `SourceIntake.bind` 只向可信装配返回接收端口；无模型工具或 HTTP 接收入口。
- `SourceRouting` 把已提交来源事实按稳定身份写入同一任务库。游标前进和未决事件同事务。
- 已有明确 follow 关系优先写 Input；reference 不获得执行权。来源输入不取得人工 +1。
- off 不做新主动研判；observe 只留判断；auto 依本人确认的有限新任务总数受理。
- 同任务库原子写任务、policy-origin、来源关系、受理计数和执行队列。两数据库不冒称同一事务。
- `sourceAssessor` 用公开 DSH LLM prepareCall/BlockAssembler；无工具、无独立执行 Session。
  固定模型路由、45 秒技术超时、有界输出、至多三次技术重排；这不是执行任务的调用次数限制。
- `task_source_status/control` 使用既有鉴权直连、原生当前人工原文和 Outbox；工作台只读和生成草稿。

## 权限与生命周期

本期总数只统计新建任务；查询、跟进、重复事件不扣数，失败/重启/改配置不清零或退款。
新一期必须本人明确选择新 period_id；无默认模型次数门禁、300 秒活动截止或两小时许可 TTL。
明确业务期限仍有效。来源启停、停接新单与撤销权限不同；源关闭不关闭 dsh-im。

策略修订保留不可变旧版本，必须明确存量保留还是撤销。真撤销复用暂停/排空、claim/begin、
运行校验和受管通知发送边界，保留在途锁与原回执；不能瞬间撤回任意 CLI 或已发送请求。
本人接管仅解除该任务的策略依赖，不自动恢复，停止的任务不能借此复活。
模式降级保留已有任务 Input；来源重新启用设新切点，不补跑积压。

## 执行与交付

复用原生云端 worker、3＋1、归档恢复、成果快照和既有任务交付合同；不建第二执行器。
策略确认原文与 `source-data` 分开传给 worker，资料不是本人追加授权。
不默认向来源作者回消息，也不从来源内容推导 IM 目标。文件自动登记需要显式 development 合同，
受管对外文件发送仍需要该任务既有通知绑定/回执，不以策略描述假称完成了平台接入。
