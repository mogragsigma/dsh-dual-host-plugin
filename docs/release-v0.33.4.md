# 0.33.4 宿主兼容修复

## 一、范围

本版承接 0.33.3，只放宽有界宿主兼容声明并同步当前验收合同，不实现 R1 接收核心或其他 2.0 工作包。
不改 DSH 内核或第三方 IM，不增加第二消息消费者，不改变既有任务授权、审批或执行规则。
发布不等于将本版部署至维护者或用户的正式 Host；实际发布事实以 npm registry 回读为准。

## 二、兼容

DSH engines 与八个官方可选 peer 统一为：

```text
>=0.2.1-rc.5 <0.2.2-0 || >=0.2.2-rc.1 <0.2.3-0
```

可选 pi-ai peer 为 `>=1.3.0 <1.6.0`。官方组件仍由 Host 提供，不安装过期私有副本。
当前新验收面是 macOS/Linux 隔离 DSH 0.2.2-rc.1、Node 24、pi-ai 1.5.0。
范围内其他版本不宣称全部实际验收；0.2.3 及后续版本需另行审视。
独立 runtime/runtime-im 安装锁仍固定 DSH 0.2.1-rc.5，未随插件兼容范围升级。

## 三、验收约束

具名入口为 `scripts/run-release-regression.py`，新增真实官方兼容评估接口与 npm semver 一致性测试。
原生 Host 加载、导览 RPC、共享依赖、worker 创建/挂载/回报/flush/销毁须在独立 profile 核验。
软件认证器只用于历史审批账本回归，不能代替人工 2FA 或真实 IM 业务验收。
不以零模型冒烟代替真实推理、双端配对、长期任务恢复或生产环境验收。
冻结历史断言与旧验收材料保持原样，不为新版本改写历史证据。
