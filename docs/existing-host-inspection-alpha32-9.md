# 既有双端 Host 只读核验候选

## 当前结论

源码候选为 `0.32.0-alpha.9`，正式两端仍为 `0.32.0-alpha.7`。
新增的是**只读证据入口**，不是六页导览接管既有生产环境的完整实现。
没有部署候选、重试失败任务、复制凭据、创建安装归属、提交、推送或发布。

当前已建立自有直连的 Host 可以在导览第 1、6 页手动核对双端状态。
云端新建、凭据交接、模型绑定及规则安装的原有授权流程保持不变。
核对结果不能替代这些流程，也不能将恢复历史配置称作“全新配置完成”。

## 模块与接口

| 位置 | 职责 |
| --- | --- |
| `bundle/onboarding-existing-host.js` | 收敛状态读取、裁剪返回字段、校验双端身份及拒绝陈旧结果 |
| `bundle/onboarding-host.js` | 原生认证导览端点、目标端公开服务装配与生命周期清理 |
| `bundle/index.js`、`bundle/link-contract.js` | 可选只读能力 `onboarding_existing: 1` 的认证协议接线 |
| `ui-source/onboarding/existing-pair.jsx` | 紧凑核对面板，手动请求，失败清除旧成功展示 |
| 全局规则及 `task-onboarding` Skill | 区分观察、归属、配置变更、实际加载与端到端验收 |

原生导览方法 `existing_pair_inspect` 只接受空参数，且从本地配对入口发起。
它通过当前认证连接调用云端 `onboarding_existing_inspect`，每次重新协商能力；
对端未装配处理器时不声明能力。没有任意远端方法、命令、路径或文件读取入口。
新能力不兼容时拒绝本次核对，不影响原生聊天，也不降级到缓存或其他 Host。

返回值逐层白名单裁剪，不包含模型 Key、凭据路径、机器人 ID、原始配置、任务正文或会话内容。
模型清单读取可能触发模型适配器的只读发现，不等于零网络请求；没有模型推理。

## 证据边界

| 展示 | 能证明 | 不能证明 |
| --- | --- | --- |
| 角色、插件版本、实例 | 本次认证响应来自当前配对端 | 后续持续在线、允许执行或停机 |
| 目标端解析路径 | 目标进程环境解析得到的候选路径 | 原生会话已经加载该目录 |
| 托管规则文件状态 | 安装器当前只读检查的结果 | 当前会话已经加载；可认领未知文件 |
| 模型清单数量 | 目标端公开目录读取结果 | Key 有效、真实推理成功、任务固定模型 |
| IM 数量 | 原生公开服务的配置清单 | 连接、发出、送达或用户已读 |
| 调度器与活动批次 | 此次读取的运行状态 | 长期空闲保证、旧任务重试授权 |
| 仓库适配器存在 | 已装配读取适配器 | 仓库权限、私有文件存在或任何写入权 |

结果明确带有 `configurationChanged: false`、`installationOwned: false`、
`executionAuthorized: false`、`endToEndVerified: false`。
仅显示观察时间，不定时刷新，不将 60 秒快照期限用作任何操作授权。

## 回归范围

- Mac 与 ECS 各 50 项定向回归：新接口、认证协议、维护屏障、默认通知、输出截断诊断。
- 原导览 208 项回归在两端通过；最终全局规则与 UI 保护另做 66 项回归。
  测试集存在重叠，不相加为独立用例总数。
- 新接口测试包含真实回环 Gateway 协商，但不是正式 DSH Host 部署验收。
- Ego 浏览器使用明确标识的模拟页面：初次请求数为 0；点击后才读取；断线后旧成功区域移除。
  宽屏、480 像素窄屏无横向溢出，按钮无重叠；问号说明可打开。
- 首轮规则扩字触发用户 48 KiB／CRLF 保护测试，已通过缩短自有规则修复；
  未提高字节上限、截断用户原文或放宽测试。

## 尚未完成

1. 六页导览中的“复用既有配置”选择、必要字段分支与独立确认回执。
2. 两端真实配置读取、可选仓库核验、真实任务及成果的统一验收视图。
3. 新候选的正式部署与完整重装后验收。
4. 原只读任务因输出额度耗尽失败仍保留，不能借新建同名任务或增加预算洗成通过。

这些是原目标的剩余项，不得把本只读面板视为收尾完成。
