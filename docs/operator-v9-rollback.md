# 运营工具 v9 显式回滚核对验收

运行时仍为 v0.24.0-alpha.14，140 文件、18 份 Skill，摘要：
6c026f1624a40ea533cc9ea415a2573727ea778d4b3b5462e6056a1b0aaac10d。

## 解决的问题

DSH 原生欢迎界面在隔离 profile patch 末尾保存 welcomeNoticeVersion，并重写为 YAML、
折行保存长字符串。默认回滚因此以 FILE_CHANGED 拒绝，避免覆盖无关配置。这一默认行为保留。

增加操作员专用 rollback-review：要求原条目语义未变，只保留末尾新增的静态非本项目条目。
输出哈希、计数和核对指纹；显式提供同一指纹后，才回退原事务已审查的本项目引用。

- ID 冲突、新项目引用、动态 YAML、别名、重复键和过期指纹仍拒绝。
- 原生新增设置和其他字节保留；仅必要的本项目路径标量可规范化为安全引号形式。
- 全局规则、Skill、旧代码、停机检查及数据库兼容检查不放宽。
- 核对输入仅保存于本机 0600 私有事务文件，不输出或上传。
- 中断恢复必须继续提供同一指纹，不自动接受后续漂移。
- 不是任意配置三方合并器，不允许覆盖用户修改。

## 回归结果

- Mac/ECS 各 125 项运营工具测试通过：原 112 项，加 13 项新回归。
- 新增覆盖只读/脱敏、默认拒绝、显式保留、过期指纹、原条目修改、动态 YAML/别名/重复键、
  ID/项目引用冲突、其他文件漂移、写入后崩溃恢复、核对记录篡改、符号链接、
  DSH 折行长路径、超限核对记录及解包 CLI 接线。
- 两端独立生成 v9 包，155 文件，SHA256 一致：
  f2bacd90288a1ca3d7f7a8b24aeeedf71ecd39a14d201260ae7daa6de906068e。

## 真实隔离现场

继续同一个尚未完成的 ECS 事务，没有重新造库或重跑已完成 campaign：

1. 核对原 patch 哈希，明确保留 1 项原生配置、回退 4 处本项目引用。
2. 按明确指纹执行回滚；不删除欢迎设置、不还原数据库。
3. 启动原 alpha.3 Host 后，三制品与原生工具探针结果和升级前完全一致。
4. 原 3 个合成历史 job 状态及尝试数保留；runs、模型调用、IM 发送均为 0。
5. 再次停止隔离 Host，4 个测试端口释放；未启动正式服务。

Mac 的此前隔离回滚记录仍有效；本轮 v9 实际接续的是 ECS，不冒称重跑了 Mac 生命周期。

## 失败证据与边界

v8 首次只读核对拒绝 DSH 折行路径，未修改配置；v9 加入该序列化形式回归后通过。
旧版启动后，原测试探针曾错误地把 YAML 当 JSON 解析；仅修复自有探针的只读解析，
未修改 DSH/第三方源码，也未据探针异常重放业务任务。最终探针已实际通过。
