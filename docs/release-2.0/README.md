# 2.0.0发行合同与验收边界

## 一、当前合同

版本2.0.0；候选准备、发布完成、Host加载与部署分别证明，不在公共说明复制私有现场进度。
需求先于UI：三条人工入口、统一云端原生执行、单用户、任务/IM权限解耦、3＋1和七天条件归档。

## 四、保留、调整与损失

保留本地普通DSH、原生规则/Skill、定时依赖、命名信号、Git和文件/回执；云端成为受管任务唯一执行端。
补齐必要原文、持续Input、确定性收尾和离线成果恢复；用户看整体进展与成果，不管理内部代理或恢复Session。
来源有限主动工作遵循已确认策略与期新建总数。蓝白叠页/便签、统一任务目标、列名与操作指引保持。

代价：本地专有资料需显式提供，云端误操作影响面与持续费用风险增加，3＋1不是费用封顶；
历史存储会增长，归档不等删除；服务商限流/认证、技术超时和明确业务期限仍然有效。
跨端文件默认32MiB、可调至512MiB技术上限，旧配置不自动扩大；不承诺全部格式、平台或最大大小性能。
