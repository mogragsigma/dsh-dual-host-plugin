# alpha32 源码同步与交接

## 范围

当前导出为 `v0.32.0-alpha.11`，仅用于产品 A 线 `dsh-dual-host-plugin` 的源码同步。
不操作 B 线任务成果仓库，不重新部署 Mac/ECS，不改变正式配置或用户规则，不创建市场版本。
源码推送由维护者独立授权，不属于业务任务的 commit/push 审批，也不继承任何业务写入许可。
**同步完成后停止，插件市场准备暂缓，等待后续功能调整。**

## 文档和制品

- README：三制品职责、工作边界、六页新环境/复用分支、环境依赖、验证命令和当前限制。
- 架构说明：新增默认通知继承、双端核验和复用确认模块，补充故障定位、状态和兼容边界。
- 正式验收：保留 S67 真实 Mac/ECS、IM、定时 worker、通知、成果和重装证据，不以本次源码检查冒充重跑。
- 交接记录：当前版本、冻结/导出区别、历史失败不重试、归属维护方法及停止点。
- 插件 + 全局规则 + Skill：版本、锁文件、协议声明和托管模板对应当前 alpha.11；20 个 Skill 打包。

## 分发清理与冻结基线

正式验收冻结清单 `candidate-bundle-alpha32-11.json` 不改写。
当前源码导出清单为 `source-bundle-alpha32-11.json`，249 文件；相对正式 bundle 仅两项非行为变化：

1. `onboarding-file-transfer.js`：敏感目录拒绝规则中的一项采用等价 Unicode 字符转义。
   拒绝范围、大小写规则、相邻非敏感目录和零授权写入行为已测试；没有删除安全检查。
2. `workbench-assets/whale-ui-states.png`：仅移除 `caBX` 来源元数据容器。
   IHDR、IDAT、IEND 原始块字节完全相同，图像尺寸和像素未重新编码，不改变角色或视觉效果。

测试说明改为中性验收代理描述，移除维护者个人路径字样，使用目标平台路径边界断言。
不改 DSH 或第三方源码，不修改运行中的正式 bundle，也不重写 Git 历史。
仓库级 `SOURCE-MANIFEST.json` 列出本次源码文件散列，排除其自身及被忽略文件，避免自引用。

## 上传边界与验证

`audit-source-export.py` 从 Git 当前源文件或 `--index` 读取待提交字节，仅允许源码根文件和六个源码目录。
拒绝私有/运行时目录、凭据文件、数据库、会话归档、日志、私钥、打包归档和符号链接；
检查二进制名称残留、常见密钥形态、带凭据 URL 等。规则不能数学证明不存在任何未知秘密，仍需人工范围核对。

只上传去敏验收摘要和合成测试，不上传真实配置、会话、账本、截图、测试机器人资料或维护备份。
A 仓库通过已有 Git CLI/SSH 快进推送并回读 main 提交号，不使用浏览器、不复制私钥、不强推。
B 仓库不读写。本次没有插件市场发布、生产部署或额外模型调用。
