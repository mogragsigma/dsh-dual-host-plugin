# 任务成果

- 先用 task_results 按部分任务名称查询进度、成果和待处理事项；名称连续包含匹配，无语义搜索。多条候选先澄清，不取第一项，不要求用户记 ID；换 DSH session 不改变任务归属。task_artifact_list 只提供登记元数据，不读取正文、不保证当前可访问。
- Gitee 既有文件：用户直接消息须明确引用相对文件路径；确认任务绑定正确仓库后调用 task_artifact_register，带当前任务与绑定版本。可选 description 必须是直接用户消息中的介绍原文，未提供则省略，不能虚构文件内容。只读固定提交，不上传、克隆、修改或发布；标为“已有文件”，不是本次 worker 生成。
- 未绑定仓库先按 task-repository 处理用户明确的关联请求，不猜仓库或路径；无仓库任务可以正常交付，禁止为凑链接自动上传 Gitee。
- 只有独立 worker 可调用 worker_artifact：保存 Markdown / txt / JSON / CSV 报告，或已有 PNG/JPEG 的严格 base64 字节（不是路径或 URL），可填写准确的 description（600 字符内）。扩展名匹配格式，≤256 KiB/文件、≤8 文件/批次、≤100 文件/任务。只写插件私有成果目录，不能指定路径、读用户文件或写工作区。随后 worker_report；批次持久成功前成果入口不可用。
- 展示入口：“大肥鱼bot → 任务与状态 → 按名称选择 → 成果物”。Gitee：介绍＋核验入口＋在 Gitee 查看；非仓库：介绍＋明确点击下载报告／查看执行会话。只呈现真实介绍和来源，旧记录缺介绍显示“介绍待补充”。不内嵌预览；执行会话不是文件下载链接。
- 每次访问入口核验任务/运行、修订、绑定、存在性、权限、大小和摘要；Gitee 文件≤1 MiB，固定提交。不存在、变更、权限失效、运行失败/中断、任务修订或换绑时明确原因，不猜链接，不自动重试或启动任务。
- 展示手动刷新；核验后的 Gitee 外链过期即撤下。外部页面使用用户自己的登录独立鉴权，服务端凭据不下发、不放入模型/IM，不绕过 iframe 安全限制。
- 当前不提供任意路径导入、自动上传、跨用户 ACL 或 OS 身份隔离。显式逐成果飞书交付须加载 task-notify，不能从查看成果自动推导上传授权。普通原生工具不因此受限，也不能绕过受管开发/发布关闭。

## 只读输入证据

- 支持的资料须经 worker_read_source 实际读取后，才有 Host 生成的 evidence.id、格式、长度、哈希和观测时间。
- worker_artifact 可传 evidence_ids（最多 8 条），仅关联当前任务修订及本批次读取；不能手填来源对象或其他 run。
- 成果介绍仍跳转 Gitee 页面或所属执行会话；来源证据不授予任意路径读取或上传权限；下载仅限已完成批次登记的自有报告。
- 证据是读取时快照，不证明资料现在未变，也不证明分析结论正确；模型和验收证据仍须分开核验。

图片登记只验证格式头、结构及尺寸，不是完整像素解码，也不新增图片生成或读取用户文件权限。JPEG 名称使用 .jpg，PNG 使用 .png；字节仍受 256 KiB 上限。


## 推送后的交付成果

- 只有提交和推送动作均完成、排空且回读证据完整时，才由持久交付账本自动形成成果条目。
- 这是已执行交付的历史记录，不是新的批准，不等于长期任务完成、发布或正式部署。
- 入口为固定提交的完整变更页，包含新增、修改和删除；不是把删除文件伪装成仍存在的文件。
- 不改原任务的仓库绑定或审批基线，不把用户关联的既有文件说成本次生成。开发阶段报告保留原历史介绍。
- 点击时只读核验当前仓库访问权、仓库身份、提交、树和父提交；失败、换绑、任务修订或证据失效不给链接。
- 列表手动刷新，只读从账本重建，无额外注册写入窗口、后台抓取或再次推送。
- 手机交付只支持明确授权的 Gitee 页面消息，不能将交付条目作为图片/文件上传，不自动发送。
- artifacts/taskboard/notification_media 契约为第2版；旧端不支持时提示升级，不静默降级为报告或已有文件。
- 开发报告和交付预览保留登记时原文，不能当作当前提交／推送结论；同时展示登记时间并引导查看后续交付账本。

## 对话查询与受控下载（第06步候选）

- 查询用 task_results；唯一匹配读取当前权威状态与成果，多项时询问任务名称／时间／版本，不凭最近会话猜任务。返回观测时间，不许诺完成时间，不轮询。
- 按成果名称定位后用 task_artifact_access 的 check / gitee / session 重新核验。Gitee 返回固定提交页面；执行会话标识仅供工作台导航，不拼接云端登录令牌或 localhost 链接发给 IM。
- 列表和查询不返回正文、下载票据或凭据，也不自动发送文件。用户明确要 IM 文件时仍按 task-notify 核验目标和授权；普通查询不能推导上传授权。
- 工作台“在对话中查询”提供可复制问题，由用户选择现有 DSH 或 IM 对话粘贴；不新建固定会话、不自动发送、不把复制当提交。
- 下载仅针对当前修订、持久完成的所属批次报告，最多256 KiB。双端支持 artifact_download:1，已登录 Host 来源校验后核对标识、权限、大小及SHA-256，浏览器再次校验后交保存。无通行密钥、无任意路径或公网下载令牌。
- Gitee 既有文件和交付变更页仍只跳转页面，不通过本接口下载或镜像；外部登录独立鉴权。
- 下载操作不会批准或执行任务。浏览器提示“已交给浏览器保存”不证明磁盘已保存；文件失效、源不可见或旧端能力不足时明确拒绝。暂停后不自动补下载，刷新后重新点击。
