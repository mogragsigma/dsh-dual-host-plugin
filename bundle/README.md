# 大肥鱼 bot 2.0 — DSH 本地与云端协作插件

> 2.0.1发行说明。功能范围、验收范围、包已发布与实例已加载是不同事实。
> 本文不记录维护者的私有部署状态；安装或更新前核对包来源、版本、兼容性和目标Host。

## 一、能力与入口

- 本地DSH、本人本地IM机器人、本人云端IM机器人三条交办通道，统一云端DSH原生执行。
- 单用户；IM所有者/白名单沿dsh-im，任务权限与IM权限独立，不新增个人凭证系统。
- 本地保留普通DSH分析、文件与对话；不接受反向受管worker，云端忙时不回退本地执行。
- 目标与必要原文归入任务，换会话仍可查询跟进；用户看整体进展与成果，不管理内部子代理。
- 云端充分使用运行账号下的原生工具，任务明确限制仍有效；无模型次数门禁、统一300秒截止或两小时重批。
- 3个普通执行名额＋最多1个已有任务人工跟进名额；等待不提前创建执行Session。
- 复用原生后台作业、子代理、长任务、定时/依赖及命名信号；空闲7天归档、后续自动恢复，不自动删除Session。
- 成果快照、相关检查、约定交付分开呈现；就绪不等于推送、发布或用户已读。
- 选定Gitee Issue的observe/auto及本人确认的本期新任务总数，默认关闭，不订阅全仓/评论/Webhook。
- 蓝白叠页工作台用于查询及指示草稿；草稿需通过对话提交，不构成第四条创建入口。
- 云端大肥鱼页可直接“打开云端工作台”，进入原生DSH；与“查看云端任务”分开，沿用既有连接。

## 二、安装与启用

- npm包名 `@mogragsigma/dsh-dual-host-plugin`，仅从仓库根打包；不另发内层bundle子包。
- [公开安装步骤](SETUP.md)，[原生profile配置模板](configuration-v2.json)。
- 宽兼容范围：`>=0.2.1-rc.5 <0.2.2-0 || >=0.2.2-rc.1 <0.2.3-0`；范围准入不等于逐版实测。
- 独立新建Host模板锁定DSH `0.2.2-rc.1`，不修改现有Host依赖；可选dsh-im锁定5.9.1。
- 真实IM证据限选定飞书本人目标，不承诺全平台。koffi构建按原生安装器确认，不私装旧版DSH组件。
- 规则/Skill安装先预览冲突，不能覆盖用户内容；六页旧只读运行时不是2.0云执行的启用证明。

## 三、范围与迁移

新任务不再走旧IM审批或短批次预算链；历史账本和兼容模块保留，不能据此恢复旧政策。
云端自主不代表本地目录自动上传、资料里的指令获得授权，或服务商额度无限。
Git以执行端仓库为基础，远端可选。Gitee commit/push已有选定真实证据；产品PR合同仍仅GitHub，
维护API创建的Gitee PR不是产品原生PR验收。

跨端文件和IM发送需要实际接线与明确目标。新文件配置默认32MiB，可调整至技术上限512MiB，
旧配置不自动扩大；不是无限大小或512MiB性能保证，IM仍受平台与网络限制。
升级须先排空、校验备份；保留旧记录和新数据，恢复使用经验证的2.0快照及独立目录，
不承诺0.33.4旧二进制可读新库。新建安装、已有实例升级和实际加载分别验收。
已有实例沿用IM/ECS配置，不用新建模板覆盖原profile；旧任务完整迁移、定时任务无感接续不作本版承诺。
不提供完整外置Watchdog、弹性云/任意BYOM或独立持续自动上线平台；不改DSH/第三方源码。
任务执行与产品仓库发布是不同授权；安装候选不授权正式部署或产品推送。

## 四、首发验收边界

选定三通道、自然跟进、原生执行、来源策略、文件与UI已有分层证据；并非全平台或任意任务零错误。
主验DSH 0.2.2-rc.1和下界0.2.1-rc.5均有隔离实装；选定真实IM为飞书，其他平台未作同等承诺。
双端及云端IM大于2MiB文件已验证，本地IM大ZIP在网络超时下按批准边界简化，不能宣称已成功。
会话归档为受控七天时钟验证；稳定性为双端超过两小时观察、首批满槽至少15分钟，非持续满载或SLA。
窄窗适配以部分可视高度换取无遮挡；不承诺FPS或任意第三方挂件兼容。
